Liquid World Models

An engine-agnostic framework for an agent that charts a world it has not finished learning — like a hero in a dungeon whose map he hasn't found, learning it room by room. It doubts its senses and its own beliefs, testifies each night before it forgets, and remembers through priced tiers. The world model is not the game engine: the engine never doubts; the internal model is built to.

Three days in the uncharted dungeon (seed 7)

Same deliberately dumb explorer every day; only the chart persists between days. The maps are drawn from the model's own chart — its beliefs, its fog, its question-mark stubs for exits never taken.

Day 1 — 21 steps, goal reached; 9 exits still uncharted.

Day 2 — 27 steps, 1 surprise (a locked door, met empty-handed); uncharted exits 9 → 1.

Day 3 — 33 steps, 0 surprises; rooms not revisited have fogged over.

Read the curve honestly

Coverage and knowledge improved: uncharted exits fell 9 → 1, and the locked door surprised the model exactly once — by day 3 the chart knows it is locked and opens to the brass key. Steps did not fall (21 → 27 → 33): day 1's speed was luck (the key room came before the locked door), and the dumb policy pays honestly for beelining to a door it cannot open. The chart learned; the policy didn't. The separation is the point.

Remembering is routed, and priced

essence (4 units):  Day 1: charted 13 places (13 new), 0 surprise(s), goal reached in 21 steps. (essence carries the distilled line; the full record is in the ledger.)
truth   (12 units): {"type": "distrusted", "day": 1, "step": 5, "place": "cellar", "trust": 0.3, "reason": "senses flagged unreliable; belief not rewritten"}

One day-1 event, two routes: essence (4 units) serves the distilled line the dream left behind; truth (12 units) opens the archived episode and returns the full testified record. A third route, reflex (1 unit), serves today's still-live episode and never opens the archive at all. Retrieval is spent from the same purse as action.

Run it

python3 -m lwm.dungeon_demo --days 3 --seed 7
python3 tests/run_tests.py   # TEST SUMMARY: 10/10 PASS

Python 3, standard library only. The contract is three methods — observe(), actions(), step() — and any engine can host a liquid model; ground truth (truth()) exists for scoring only and is structurally unreachable from the agent.
