Liquid World Models

An engine-agnostic framework for an agent that charts a world it has not finished learning — like a hero in a dungeon whose map he hasn't found, learning it room by room. It doubts its senses and its own beliefs, testifies each night before it forgets, and remembers through priced tiers. The world model is not the game engine: the engine never doubts; the internal model is built to.

That framework is the seed of a wider programme, and this repo is now its record: the chart machinery run against real JEPA perception on the Thor, two micro-model farms whose members are called per-purpose, old games used as sealed learning fields with scores as receipts, and a spec-box league for scripted game players. Every result is filed as a full report with its process in the body — and the negatives are filed as negatives, in the index below, in the same type size as the wins.

State of the record: 2026-10-27. The demo below is the framework's own shipped output; everything after it is the filed programme, each claim verified against the document it names. Full reports: github.com/patchwork-quilt/liquid-world-model.

Three days in the uncharted dungeon (seed 7)

Same deliberately dumb explorer every day; only the chart persists between days. The maps are drawn from the model's own chart — its beliefs, its fog, its question-mark stubs for exits never taken.

Read the curve honestly

Coverage and knowledge improved: uncharted exits fell 9 → 1, and the locked door surprised the model exactly once — by day 3 the chart knows it is locked and opens to the brass key. Steps did not fall (21 → 27 → 33): day 1's speed was luck (the key room came before the locked door), and the dumb policy pays honestly for beelining to a door it cannot open. The chart learned; the policy didn't. The separation is the point.

Remembering is routed, and priced

essence (4 units):  Day 1: charted 13 places (13 new), 0 surprise(s), goal reached in 21 steps. (essence carries the distilled line; the full record is in the ledger.)
truth   (12 units): {"type": "distrusted", "day": 1, "step": 5, "place": "cellar", "trust": 0.3, "reason": "senses flagged unreliable; belief not rewritten"}

One day-1 event, two routes: essence (4 units) serves the distilled line the dream left behind; truth (12 units) opens the archived episode and returns the full testified record. A third route, reflex (1 unit), serves today's still-live episode and never opens the archive at all. Retrieval is spent from the same purse as action.

Run it

python3 -m lwm.dungeon_demo --days 3 --seed 7
python3 tests/run_tests.py   # TEST SUMMARY: 10/10 PASS

Python 3, standard library only. The contract is three methods — observe(), actions(), step() — and any engine can host a liquid model; ground truth (truth()) exists for scoring only and is structurally unreachable from the agent.

ReportVerdict

VJEPA-PROBE Transitions are in the representations: a frozen V-JEPA view-pair + the action + a linear readout recovers what happened at 0.976 vs 0.711 for the strongest after-view-only readout — and the margin is exactly where a single view is blind in principle, telling “I stayed” from “I arrived.”

ReportVerdict

Games — sealed fields, scores as receipts

ReportVerdict
GAME-SUBSTRATES Scout of game environments as learning substrate: NetHack ranked first (a fresh procedural dungeon per game, strictly turn-based so slow models can digest off-turn, death itemised as a born receipt), interactive fiction via dfrotz second (the purest language world), the house game Sail and Sink third (real-time, but its dial layer is learnable and the page self-scores).
GAME-PLAYERS Scout of existing algorithmic players as wrappable agents: qw ranked first — it exposes a declarative goals language, so an agent steers it by writing its config — then AutoAscend, then walkthrough→Jericho. The Angband Borg is sealed (in-process only): benchmark duty, wrap last.
HARNESS-EXPERIMENT Clean negative. Can barely-functioning models work inside a sophisticated harness? No: the bare 360M scored 22/40 and beat every other arm — harnessed 135M 14, the bare 0.6B control 17, harnessed 360M 6. Tiny models parrot the scaffold's intermediate format instead of executing it. The lesson the receipts argue: less scaffold, more code.
NETHACK-CHART The chart-only league: no language model anywhere — a scripted explorer feeding the framework's Chart, unmodified, inside NetHack. Median 5 true rooms × 1,061 turns across 10 runs, and the map was true: 0 merges, 0 splits, scorer-judged (one kept, unexplained one-room discrepancy in run 5).
QW-MANAGER A 0.6B farm brain managing the proven DCSS bot qw: median tied with stock, 128–128 — because only 3 of its 10 configs were valid; the failure was vocabulary precision (Runes: for the grammar's Rune:), not strategy. On the 3 seeds it actually managed, it won 2 and lost 1. Plumbing proven, management unproven.
QW-REMATCH The rematch with the 7B as manager: 10/10 configs valid — precision did arrive with size — and it bought almost nothing. The bigger manager manages by deference (stock defaults spelled longhand; 9 of 10 games event-for-event identical to stock), and its one real act of management was the worst managed game of either round. Round 1's flawed-but-bold 0.6B out-managed it.
THREE-SPEED A three-speed agent in one pi harness on NetHack — TypeSafe Jev as reflex gauge, pi for decisions, pi again for slow reflection that re-sets the gates: it matches the flat scripted explorer (4,113 vs 4,563.5) and does not beat it. The layers are individually legible: reflexes alone survive 1,489 turns and chart 1 room; decisions triple the rooms; reflection provably steers (DESCEND chosen 0 times in ~300 replies before a directive, 76 times after). The chart never lied under any configuration — 0 merges / 0 splits in 11/11 runs.

The ESP32 chess box — a fixed hull, swappable crews

ReportVerdict
ESP32-BOX-FORMAT The format: a pinned ESP32-class hull (520 KB SRAM, 4 MB flash, 10:00 clock) that never changes, so season-over-season improvement is attributable; crews are source + build recipe, flashable in principle. The proof games bought the §6 interface contract — explicit relay acknowledgement, the referee owns the position — after micro-Max forfeited a won-looking game to its own golfed legality checker.
SEASON0 Season 0 (9 games, 446 plies, zero desyncs / illegal moves / flag falls): hoardbox champion. And Underfill confirmed — mean crew binary 1.7% of the flash cap, carried manifest data 0 bytes for every crew; the only budget anyone spent was RAM. Legality is the floor, not the event.
SEASON1 Season 1 (12 games, 1,013 plies, every game checkmate, zero incidents): the order holds but compresses, and two of three v2 crews beat their own parents — the champion's heir did not. Pruning confirmed as behaviour, one axis over: eight documented cuts at the workbench, in RAM (a first transposition table measured 560 KiB against the 520 cap and was cut before the crew froze); flash is still 1.73% used, for a diagnosed reason — nine honest games only support hundreds of book entries.
